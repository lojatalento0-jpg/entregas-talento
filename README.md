# Entregas Talento — app do motorista (piloto)

Página instalável no celular do motorista da Loja Talento. Funciona sem sinal e envia os registros quando houver internet.

- Este repositório tem **só o código**. Nenhum dado de cliente fica aqui.
- Os dados (lista do dia, registros e fotos) ficam no banco da loja e só aparecem depois do login de cada motorista.
- Status: piloto, sem uso operacional homologado.
